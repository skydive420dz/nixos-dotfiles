#+title: Machine inventory

* Scope
Manually reviewed reference for machine identity, configuration ownership and
configured network addresses. Addresses are not proof of current reachability.
This file grants no permission to connect, modify, deploy or reboot.

No incident history, live-status tracking or automatic updates belong here.
Update deliberate configuration facts through user-reviewed edits only.
