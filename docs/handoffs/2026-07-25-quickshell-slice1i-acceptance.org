* Contract And Change
The controlling contract is
[[file:../audits/2026-07-19-quickshell-slice1-remainder.org][the Slice 1
remainder audit]], sections =R8 - CAVA Stale Samples= and =Slice 1I - Analyzer
Freshness=.

The payload changes exactly one path:

- =config/quickshell/modules/media/MediaAnalyzer.qml=

The analyzer now records the receipt time of each accepted CAVA row and expires
live levels after =sampleFreshnessMs: 500=.  At the retained 24-fps CAVA
cadence this allows approximately 12 missed rows before declaring the sample
stale.  Expiry clears live levels so the unchanged 90-ms fallback timer can
publish fallback animation again.

The freshness timer rechecks the current sample age and rearms only for the
remaining interval.  An older timeout therefore cannot clear a newer sample.
Blank or inactive output does not refresh freshness, while a numeric all-zero
row remains a valid live sample.  Media deactivation and CAVA process exit both
clear the timestamp and levels.  Final parser output is drained before exit
clearing, so exit state wins deterministically.

A later valid row restores live mode through the same running process.  The
change deliberately adds no automatic CAVA restart or crash-loop policy.
