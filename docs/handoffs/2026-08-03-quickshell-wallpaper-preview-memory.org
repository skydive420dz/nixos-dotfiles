* Change

[[../../config/quickshell/modules/wallpaper/WallpaperSelector.qml][WallpaperSelector.qml]].
Both still-image and generated-video previews now set =sourceSize= to their
displayed width and height.  The current picker contains 27 files, of which 22

change prevents thumbnail cards from decoding those sources at original size.

the measured allocation directly; broader Slice 6 work remains conditional on
new evidence.

* Controlled Runtime Evidence
Baseline and candidate used the same installed Quickshell package and copied
the real Wayland-session environment.  Each ran from an isolated worktree while
the normal user service was stopped under an automatic rollback trap.

Memory values below are Linux =/proc= KiB:

| State | Baseline RSS | Baseline anonymous | Candidate RSS | Candidate anonymous |
|-------+--------------+--------------------+---------------+---------------------|
| Picker closed, fresh |       235560 |              67180 |        230020 |               65656 |
| First open peak      |       704620 |             520800 |        268196 |               98392 |
| Closed after test    |       237480 |              70024 |     257972-260824 |         88192-91044 |

The open-time RSS increase fell from 469060 KiB to 38176 KiB, a 91.9% reduction.
A second candidate open peaked at 265732 KiB and then declined after close; it
did not ratchet upward.  The baseline also returned near its fresh value, so
this records a large transient allocation rather than claiming a permanent
leak.

After both controlled runs, the rollback trap restored the normal
=quickshell.service=.  It was =active/running= with =Result=success= and
=NRestarts=0=.  No wallpaper was selected or modified during the probes.
