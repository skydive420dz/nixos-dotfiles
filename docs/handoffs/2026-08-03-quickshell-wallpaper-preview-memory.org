the real Wayland-session environment.  Each ran from an isolated worktree while
the normal user service was stopped under an automatic rollback trap.

The open-time RSS increase fell from 469060 KiB to 38176 KiB, a 91.9% reduction.
A second candidate open peaked at 265732 KiB and then declined after close; it

this records a large transient allocation rather than claiming a permanent
leak.

After both controlled runs, the rollback trap restored the normal
=quickshell.service=.  It was =active/running= with =Result=success= and
=NRestarts=0=.  No wallpaper was selected or modified during the probes.

* Acceptance Boundary
Acceptance is limited to the four-line preview-memory optimization.  Slow wheel
travel is a separate UX micro-slice and does not block Slice 6A.  If selected,
that work must first test the smallest native =Flickable= wheel-distance
adjustment; it does not authorize a =GridView= rewrite.

dual-output validation remain separate and unauthorized.
