* Contract And Change
This implements only the third event-driven source in
[[file:../audits/2026-07-14-quickshell-optimization.org][the original Slice 4
roadmap]]: native Bluetooth adapter and connected-device state.

The payload changes exactly
[[file:../../config/quickshell/modules/status/StatusController.qml][StatusController.qml]]:

- =Quickshell.Bluetooth= is imported as =BluetoothApi= so its =Bluetooth=
  singleton cannot be confused with the sibling =Bluetooth.qml= view;
- =bluetoothAvailable= is true when =defaultAdapter= exists, preserving the
  former controller-presence contract even when the adapter is not powered;
- =bluetoothConnected= is true when any known device on the default adapter
  reports its native =connected= property;
- the old Bluetooth parser keys, startup probe, 30-second timer, Bash process,
  two =bluetoothctl= commands, and =grep= are deleted.

The two line-local =qmllint disable unresolved-type= directives cover an
installed Quickshell 0.3 tooling-metadata false positive.  The qualified
runtime import and native bindings were exercised successfully; widening the
checker allowlist would add code without improving runtime safety.

The existing scalar interface into =StatusCluster.qml= and =Bluetooth.qml=
is unchanged.  The three-state glyph, colors, geometry, and exact BlueTUI click
command remain byte-identical.  Networking, traffic sampling, PipeWire,
UPower, clock, CAVA, output fan-out, packages, and Nix options were not changed.
No helper, dependency, controller, or persistent test file was added.
