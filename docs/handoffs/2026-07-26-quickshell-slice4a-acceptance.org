* Claim Boundary
At the accepted two-second cadence, the deleted path launched one Bash,
=wpctl=, and =awk= execution per sample: 5,400 theoretical executions per hour.
Removing it reduces the source-derived steady status budget from 14,280 to
8,880 executions per hour, about 38%.

This is a process-churn and event-latency result, not a measured CPU, memory,
GPU, battery, or power improvement.  The native tracker adds a persistent
PipeWire binding whose resource cost was not separately profiled.

This slice does not:

- change volume control or OSD transport;
- switch the default sink or test a hardware disconnect/reconnect;
- require a second monitor because controller fan-out and the view are
  unchanged;
- begin UPower, Bluetooth, networking, traffic, or native Hyprland migration;
- by itself authorize NixOS/Home Manager activation, publication, =main=
  promotion, worktree removal, branch deletion, or broader cleanup.
