* Contract And Change
The payload changes only
[[file:../../config/quickshell/modules/status/StatusController.qml][StatusController.qml]]:
eight insertions and 45 deletions.

It replaces the 15-second network identity and Wi-Fi signal poller with
=Quickshell.Networking= state:

- the first connected supported native device supplies its name and
  Wi-Fi/Ethernet type;
- the connected Wi-Fi network supplies =signalStrength=;
- a native device-name change still enters the accepted Slice 1H
  =setNetworkDevice= path.

The old parser, timer, process, Bash command, two =nmcli= commands, and two
=awk= commands are deleted.  One two-second traffic =Process= remains because
the installed Quickshell 0.3.0 networking model does not expose RX/TX byte
counters.

The implementation deliberately means *first connected supported device*, not
default route.  Quickshell 0.3.0 exposes connected devices and Wi-Fi signal but
not an exact default-route selector.  Exact default-route selection therefore
remains deferred rather than being approximated or hidden behind a new helper.

No NetworkManager connection, route, or device was changed.  No view,
geometry, icon, color, click action, package, dependency, or helper changed.
