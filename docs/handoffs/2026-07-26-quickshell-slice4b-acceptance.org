* Contract And Change
This implements only the second event-driven source in
[[file:../audits/2026-07-14-quickshell-optimization.org][the original Slice 4
roadmap]]: native UPower battery and charge transitions.

The payload changes exactly
[[file:../../config/quickshell/modules/status/StatusController.qml][StatusController.qml]]:

- one =Quickshell.Services.UPower= import was added;
- =UPower.displayDevice= now supplies presence, percentage, and state;
- =UPower.onBattery= makes plug ordering independent of separate device-state
  notifications;
- the existing =battery=, =charging=, and =batteryStatus= interface remains;
- the old battery parser branches, startup probe, ten-second timer, and
  Bash/two-=cat=/two-=head= process were deleted.

The native state mapping is explicit:

| Native state | Existing status contract |
|--------------+--------------------------|
| Global on-battery or =Discharging= | =Discharging= |
| =Charging= | =Charging= |
| =FullyCharged= | =Full= |
| =PendingCharge=, =PendingDischarge=, or =Empty= while not globally on-battery | =Not charging= |
| =Unknown= | =Unknown= |

=ready && isPresent= suppresses unavailable startup data, and Quickshell's
normalized =0..1= percentage is converted back to the existing integer
=0..100= contract.  The existing first-sample suppression and idempotent
transition handler remain the sole battery OSD owner.

=Battery.qml=, =StatusCluster.qml=, OSD transport and rendering, click
launchers, network traffic, networking, Bluetooth, PipeWire, clock, CAVA,
geometry, colors, and output fan-out were not changed.  The traffic, network,
and Bluetooth process pollers remain.  No helper, dependency, Nix option,
controller, or persistent test file was added.
