* Contract And Change
This is a behavior-preserving simplification, not a visual redesign.  Against
the checkpoint its code payload changes 31 paths: 70 insertions and 531
deletions, for a net removal of 461 lines.

- Launcher discovery now uses Quickshell's native
  =DesktopEntries.applications= model.  The custom parser and
  =modules/launcher/apps.json= are deleted.
- BlueTUI and WireMix are ordinary Home Manager =xdg.desktopEntries= in
  =home/modules/services/quickshell.nix=.
- Launcher and clipboard toggles use their existing unique Quickshell
  =IpcHandler= targets through =qs ipc call=.  The signal-file toggle helpers
  are deleted.
- Theme and wallpaper text reads use Quickshell =FileView= instead of spawning
  =cat=.
- Dead weather code, unused object IDs, no-op visual wrappers, and the obsolete
  numeric network-rate formatting path are removed.  The current dotted
  network graph remains.
- =scripts/check-quickshell= keeps the checks that protect the current source
  and drops checks for deleted compatibility files.

Deleted helpers:

- =scripts/launcher-apps=
- =scripts/launcher-toggle=
- =scripts/clipboard-toggle=
- =scripts/weather=
- =config/quickshell/modules/launcher/apps.json=

=IpcHandler= replacement was reverted after the installed Quickshell 0.3 CLI
rejected arguments to =qs ipc call=.  Keeping the compatible path avoids a
