   already lives once at the shell root.  It now owns =timeText=, =dateText=,
   unchanged formatting, and one one-shot timer.
2. [[file:../../config/quickshell/modules/status/StatusCluster.qml][StatusCluster.qml]]
   binds those two strings into every output's clock view.
3. [[file:../../config/quickshell/modules/status/Clock.qml][Clock.qml]] retains
   its exact geometry, fonts, colors, alignment, and two-line rendering while
   dropping its per-output timer and formatter.

After every update, the controller schedules the next callback with:

#+begin_src qml
60000 - date.getSeconds() * 1000 - date.getMilliseconds()
#+end_src

The one-shot timer recomputes that delay after every callback instead of
accumulating the phase or delay of a repeating timer.  The two output views bind
to the same formatted strings, so they receive one shared rollover.

No new controller, singleton, process, dependency, QML type, configuration
option, test framework, or shell/bar plumbing was added.
