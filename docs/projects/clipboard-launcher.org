** Current
:PROPERTIES:
:CUSTOM_ID: current
:END:
- Accepted live =main= uses =launcher.toggle()= and =clipboard.toggle()= IPC functions, Quickshell's native desktop-entry model, and Home Manager XDG entries for BlueTUI and WireMix.
- The native cleanup is promoted and live on generation 885.  See the [[../handoffs/2026-08-03-quickshell-native-cleanup-acceptance.org][acceptance handoff]].
- Image clipboard entries are detected from =cliphist list= binary markers and get a selected-item thumbnail preview generated under =$XDG_RUNTIME_DIR=.
- The old fuzzel fallbacks, signal-file toggle helpers, custom launcher parser, and custom app JSON are retired.

** Decisions
:PROPERTIES:
:CUSTOM_ID: decisions
:END:
- Keep launcher and clipboard as separate tools until focus restoration, keyboard navigation, and close behavior are boring and reliable.
- Native Quickshell is the accepted owner; the fallback scripts are retired.
- Prefer Quickshell's native IPC and desktop-entry APIs over repository-specific signal files and parsers.
- Use Quickshell screen binding for layer windows.
- Keep native launcher results apps-only by default. Window search is noise for the current workflow and can return later as an explicit mode if it earns its place.
- Follow the Quickshell ownership rules: =root/= owns surfaces, =modules/<name>/= owns behavior, =common/= owns reusable primitives only.
- Avoid full-screen invisible masks unless the overlay is intentionally click-out-to-close and the mask is verified not to steal unrelated input.
